# Agentic Payments Timeline (2024–2026)

English | [简体中文](./TIMELINE.zh-CN.md)

A dated, source-linked timeline of protocol launches, official payment MCP servers, card-network agent programs and governance changes in AI agent payments.

Last updated: 2026-09-29. Every event links to a primary source; the verbatim supporting quote for each row is in [timeline.csv](./timeline.csv).

## 2024

- **2024-11-25**: Anthropic: Open-sourced the Model Context Protocol (MCP), the connector standard payment MCP servers are later built on ([source](https://www.anthropic.com/news/model-context-protocol))

## 2025

- **2025-04-29**: Mastercard: Unveiled Agent Pay, tokenized agentic payments technology giving consumers control over what an agent can purchase ([source](https://newsroom.mastercard.com/news/press/2025/april/mastercard-unveils-agent-pay-pioneering-agentic-payments-technology-to-power-commerce-in-the-age-of-ai))
- **2025-04-30**: Visa: Launched Visa Intelligent Commerce, opening its payments network to AI-agent developers ([source](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.21366.html))
- **2025-05**: Coinbase / x402: x402 protocol launched, embedding payments into HTTP via the 402 status code ([source](https://www.x402.org/writing/x402-v2-launch))
- **2025-06-10**: Adyen: Began piloting its MCP server for building payments integrations with LLMs ([source](https://www.adyen.com/knowledge-hub/mcp-release))
- **2025-06-26**: Skyfire: Publicly launched its identity-and-payments platform for AI agents, later described as the KYAPay protocol ([source](https://skyfire.xyz/skyfire-launches-identity-and-payments-for-autonomous-ai-agents/))
- **2025-06-30**: Razorpay: Launched its MCP server connecting AI tools to Razorpay's payment infrastructure ([source](https://razorpay.com/newsroom/razorpay-becomes-indias-first-payment-gateway-to-launch-mcp-server-for-instant-ai-payment-integration/))
- **2025-07-28**: Mollie: Launched its AI-ready MCP server to let merchants automate workflows via AI tools ([source](https://www.mollie.com/news/mollie-launches-ai-ready-mcp-server))
- **2025-09-16**: Google: Announced the Agent Payments Protocol (AP2), using signed Mandates as proof of user authorization ([source](https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol))
- **2025-09-16**: Google: Launched the A2A x402 extension with Coinbase, Ethereum Foundation and MetaMask for agent-based crypto payments ([source](https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol))
- **2025-09-23**: Cloudflare / Coinbase: Announced intent to launch the x402 Foundation to govern the x402 protocol ([source](https://blog.cloudflare.com/x402/))
- **2025-09-29**: OpenAI / Stripe: Released the Agentic Commerce Protocol (ACP) and launched Instant Checkout in ChatGPT, starting with Etsy ([source](https://stripe.com/newsroom/news/stripe-openai-instant-checkout))
- **2025-10-14**: Visa: Announced the Trusted Agent Protocol (TAP), developed with Cloudflare ([source](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.21716.html))
- **2025-10-28**: PayPal: Partnered with OpenAI, adopting the Agentic Commerce Protocol for ChatGPT commerce ([source](https://newsroom.paypal-corp.com/2025-10-28-OpenAI-and-PayPal-Team-Up-to-Power-Instant-Checkout-and-Agentic-Commerce-in-ChatGPT))
- **2025-11-25**: Checkout.com: Announced support for the Agentic Commerce Protocol for enterprise merchants ([source](https://www.checkout.com/newsroom/checkout-adopts-acp-backed-by-openai-to-power-agentic-commerce-for-enterprise-merchants))
- **2025-11-25**: MCP Steering Committee: Marked MCP's first anniversary with a new specification version release ([source](https://blog.modelcontextprotocol.io/posts/2025-11-25-first-mcp-anniversary/))

## 2026

- **2026-01-11**: Google: Announced the Universal Commerce Protocol (UCP), built with Shopify, Etsy, Wayfair, Target and Walmart ([source](https://developers.googleblog.com/under-the-hood-universal-commerce-protocol-ucp/))
- **2026-03-18**: Stripe / Tempo: Announced the Machine Payments Protocol (MPP), co-authored by Tempo and Stripe ([source](https://stripe.com/blog/machine-payments-protocol))
- **2026-03-25**: OpenAI: Said it is allowing merchants to use their own checkout experiences instead of the initial Instant Checkout, to focus on product discovery (as reported) ([source](https://www.thekeyword.co/news/openai-chatgpt-instant-checkout-scrapped))
- **2026-04-08**: Visa: Launched Intelligent Commerce Connect, a single integration for agents to pay and merchants to accept agentic transactions ([source](https://usa.visa.com/about-visa/newsroom/press-releases.releaseId.22276.html))
- **2026-04-28**: Google: Donated the Agent Payments Protocol (AP2) to the FIDO Alliance ([source](https://blog.google/products-and-platforms/platforms/google-pay/agent-payments-protocol-fido-alliance/))
- **2026-05-11**: Circle: Launched Circle Agent Stack, including Agent Wallets with policy-based USDC spend limits ([source](https://www.circle.com/blog/introducing-circle-agent-stack-financial-infrastructure-for-the-agentic-economy))
- **2026-06-02**: Crossmint: Launched an agentic cards API using Visa Intelligent Commerce and Basis Theory, letting agents pay with real Visa cards ([source](https://www.prnewswire.com/news-releases/crossmint-launches-agentic-cards-api-using-visa-intelligent-commerce-and-basis-theory-302786624.html))
- **2026-06-10**: Mastercard: Launched Agent Pay for Machines for high-frequency, low-value machine-to-machine payments ([source](https://thepaypers.com/payments/news/mastercard-launches-agent-pay-for-machines-for-ai-commerce))
- **2026-06-16**: Adyen: Announced Adyen Agentic, a suite of modular APIs for selling through conversational AI platforms ([source](https://www.adyen.com/press-and-media/adyen-agentic))
- **2026-06-18**: Airwallex: Launched AgentOS, a toolkit for operating an Airwallex account from AI agent environments ([source](https://www.airwallex.com/global/blog/introducing-airwallex-agentos-manage-your-financial-operations-in-your-preferred-agent-environment))
- **2026-07-01**: Cloudflare: Announced Monetization Gateway, letting customers charge AI agents for web pages, datasets, APIs or MCP tools ([source](https://blog.cloudflare.com/monetization-gateway/))
- **2026-07-14**: Linux Foundation: x402 Foundation had its operational launch with 40 member organizations ([source](https://www.linuxfoundation.org/press/linux-foundation-announces-operational-launch-of-x402-foundation-to-standardize-internet-native-payments-for-ai-agents-and-applications))
- **2026-09-28**: PinkWallet (Pink Agentic AI Payment): Published the Agentic Payments Readiness Report 2026, scoring 13 payment providers on 7 agent-readiness dimensions (by the maintainers of this list) ([source](https://github.com/Pink-Agentic-Payments/agentic-payments-readiness/releases/tag/v1.1))
- **2026-10-31**: Stripe: Scheduled change: Stripe MCP stops accepting full-access secret keys or restricted keys without the Agent tag ([source](https://docs.stripe.com/mcp)) (scheduled)
