# Contributing

Pull requests welcome. To be added, a link must be:

- **Public** — no login wall to read the page being linked.
- **Working** — resolves with a normal HTTP 200 (or a redirect that ends in one) at the time you submit.
- **Relevant** — about AI agents making payments: a protocol, an MCP server or SDK that touches payments, a spending-control/guardrail product, or research/analysis about agent payments specifically. General fintech or general AI-agent tooling with no payment angle doesn't fit.
- **Backed by a quote from the linked page itself** — no marketing paraphrase, no claims the source page doesn't make.

## How to submit

1. Open a PR adding your entry in the correct alphabetical position within its section.
2. Write a one-line, factual, non-promotional description sourced directly from the page you're linking. Quote it, don't summarize it into a superlative.
3. No emojis, no affiliate links, no tracking parameters (except our own `utm_source=github&utm_medium=awesome-list` on pinkwallet.com links, which stays as-is).
4. If you work at a company already listed and think a line is wrong or out of date, say so in the PR with a link to the correct current page — we'll re-verify and update.

## What gets removed

Entries get pulled if the link goes dead, the project is abandoned with no update in a long time, or the description turns out to overstate what the vendor's own page says.
